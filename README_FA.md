## این برنامه چیست؟

فرض کنید دو سرور دارید: یکی در ایران و یکی خارج از ایران. گاهی به‌خاطر
محدودیت‌های اینترنتی، دسترسی مستقیم به سرویس‌های داخل ایران از خارج (یا
برعکس) ممکن نیست. ایکسیستنس پنل یک صفحه وب ساده است که با یک **تونل امن**
این دو سرور را به هم وصل می‌کند تا ترافیک از مسیر تونل عبور کند.

همه‌چیز با مرورگر انجام می‌شود: سرورها را اضافه می‌کنید، نوع تونل را انتخاب
می‌کنید و دکمه اجرا را می‌زنید. نصب، اجرا، نظارت و راه‌اندازی مجدد با خود
پنل است.

## کدام تونل را انتخاب کنم؟

| تونل | کی به درد می‌خورد؟ |
| --- | --- |
| **معکوس (Reverse)** (پیشنهاد اول) | وقتی سرور ایران پشت فایروال است. ایران خودش به خارج وصل می‌شود، پس لازم نیست پورتی در ایران باز کنید. |
| **مستقیم (Direct)** | وقتی دو سرور مستقیم به هم دسترسی دارند. ساده‌ترین حالت با فقط یک سرور. |
| **بک‌هاول (Backhaul)** | وقتی سریع‌ترین تونل معکوس را با تنظیمات پیشرفته می‌خواهید. |
| **اف‌آر‌پی (FRP)** | وقتی چند پورت و پروتکل مختلف را با یک تونل می‌خواهید. |
| **گاست (GOST)** | یک رله کوچک و پرسرعت TCP/UDP. |
| **اس‌اس‌اچ (SSH)** | اگر با SSH راحتید. قطع شود خودش وصل می‌شود. |
| **ایکس‌ری (Xray)** | اگر یک اینباند VLESS/VMess/Trojan/Shadowsocks دارید (مثلاً در 3X-UI) و می‌خواهید پنل آن را اجرا کند. |
| **ایکس-یوآی (X-UI / 3X-UI)** | اگر کانفیگ شما از قبل در پنل X-UI است — فقط وصلش کنید تا ایکسیستنس مراقبش باشد. هیچ برنامه اضافه‌ای اجرا نمی‌شود. |
| **انتقال پورت** | یعنی «پورت X را اینجا باز کن و به سرویس Y آنجا بفرست». به‌صورت پیش‌فرض **کاملاً خودکار** است: فقط سرویس را نشان بدهید و پنل خودش یک پورت آزاد انتخاب می‌کند. اگر خواستید، حالت پیشرفته را باز کنید و پورت را دستی بدهید. |

## نصب روی سرور (اوبونتو ۲۲.۰۴ / ۲۴.۰۴)

فقط یک خط. نصب‌کننده ۲–۳ سؤال ساده می‌پرسد (پورت، ایمیل مدیر) و بقیه را خودش
انجام می‌دهد: برنامه‌های سیستمی، Node 22، برنامه‌های تونل (`backhaul`،
`frp`، `gost`، `xray`)، دیتابیس و سرویسی که با روشن شدن سرور بالا می‌آید.

```bash
curl -fsSL https://raw.githubusercontent.com/insekt1024/xistance-panel/master/scripts/bootstrap.sh \
  -o /tmp/xp-install.sh && sudo bash /tmp/xp-install.sh
```

بعد مرورگر را باز کنید: `http://<آی‌پی-سرور>:8080` و وارد شوید.

سرور کوچک و ارزان دارید؟ مشکلی نیست: اگر رم کمتر از حدود ۱.۵ گیگ باشد،
نصب‌کننده خودش حافظه کمکی (swap) می‌سازد و با حالت کم‌حافظه بیلد می‌گیرد، و
تونل‌های لینک‌شده به X-UI هیچ پردازش اضافه‌ای اجرا نمی‌کنند.

## کار روزمره (۳ قدم)

1. **گره‌ها (Nodes)** — سرور ایران و سرور خارج را اضافه کنید (آی‌پی + مشخصات
   ورود SSH). پنل خودش اتصال را تست می‌کند.
2. **تونل‌ها ← تونل جدید** — ایران و خارج را انتخاب کنید، از جدول بالا یک نوع
   تونل بردارید، ۲–۳ فیلد را پر کنید و اجرا کنید.
3. **تمام** — داشبورد وضعیت، ترافیک و لاگ را نشان می‌دهد. اگر ارتباطی قطع
   شود، پنل خودش دوباره راهش می‌اندازد.

## ایکس‌ری و X-UI / 3X-UI

- **تونل Xray:** پنل 3X-UI را باز کنید و آدرس، پورت و UUID/رمز اینباند را در
  ویزارد ایکسیستنس کپی کنید. پنل فایل `xray.json` را می‌سازد و `xray` را اجرا
  می‌کند (نمونه در `tunnels/examples/xray-vless.json`).
- **لینک X-UI:** آدرس پنل 3X-UI به‌همراه نام کاربری و رمز را بدهید (و اگر
  خواستید شناسه اینباند). پنل با HTTPS ورود را چک می‌کند و مراقبش می‌ماند.
  برای این نوع تونل چیزی نصب نمی‌شود.
